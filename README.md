# release-parser-web

Dockerized Web access for [release-parser](https://github.com/pr0pz/scene-release-parser)

## Installation
* Install Docker if not already done
* Clone this repository
* Launch with `docker compose up -d`
* Access `http://IP_OF_THE_SERVER:8765/?Release=NAME_OF_THE_RELEASE`
That's all folks!
